# QUANTAURA

## Stop agents before they act.

**Execution Authorization Kernel** for AI agents — sign, policy-check, authorize, then execute.

Also ships **QPIE**: a physical-intelligence lab (DEC, gauge theory, Schwinger ED, discovery firewall).

### Install

```bash
pip install quantaura-core
quantaura-serve --reload
```
